# 🎸 My HNG Stage 1B Profile Card

Hello! I'm **PStev**. This is my second project for the HNG Internship. It’s a simple, clean, and accessible profile card built with pure HTML, CSS, and JavaScript.

## 🌟 What this project does
I built this card to show that I can create a web page that looks good on both phones and computers, while making sure the code is easy for computers to "test."

### Key Features:
* **The Heartbeat:** A live clock showing the time in milliseconds (it ticks fast!).
* **Responsive:** It looks great on your phone and automatically adjusts for your desktop.
* **Accessible:** I used special HTML tags so that people using screen readers can navigate my card easily.

---

## 🛠️ How I built it
I used the "big three" of web development:
1. **HTML:** To build the skeleton of the card.
2. **CSS:** To make it look modern and professional.
3. **JavaScript:** To make the clock update every single millisecond.

---

## 🧪 Testing Info
For the HNG mentors and automated tests, I have added the required `data-testid` attributes to these parts of the card:
* `test-profile-card` (The whole card)
* `test-user-name` (My name)
* `test-user-bio` (My short bio)
* `test-user-time` (The ticking clock)
* `test-user-avatar` (My profile picture)
* `test-user-social-links` (My social media links)
* `test-user-hobbies` (My hobby list)
* `test-user-dislikes` (My dislike list)
* verify responsiveness on mobile  and Desktop
* All links verified and functional
* Image alt-text included for accessibility



## 🚀 How to see it
1. **Live Link:** https://testable-profile-card01.netlify.app/
2. **Run locally:** Download the files and open `index.html` in your browser.
